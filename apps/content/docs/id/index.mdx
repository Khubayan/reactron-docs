**Reactron Docs** adalah ruang belajar untuk memahami dasar-dasar web: mulai dari HTML, CSS, JavaScript, hingga menjelajahi library & framework modern seperti React dan Next.js.

Platform ini dirancang agar pembelajaran terasa efektif, up-to-date, seru, dan fleksibel, khususnya untuk para anggota **Reactron**.

## ✨ Materi Reactron Docs

- **HTML 📄**  
  Mulailah perjalananmu dengan memahami tulang punggung dari setiap website. Dari tag sederhana hingga struktur yang kompleks, di sini kamu belajar bagaimana sebuah halaman web dibentuk dari nol.

- **CSS 🎨**  
  Ubah halaman polos menjadi karya yang enak dipandang. Dengan CSS, kamu bisa mengatur warna, layout, hingga animasi yang bikin website terlihat hidup dan modern.

- **JavaScript ⚡**  
  Saatnya memberi “nyawa” pada website. JavaScript membuat halaman jadi interaktif—mulai dari tombol yang bisa diklik, form yang dinamis, sampai efek yang bikin pengalaman pengguna lebih seru.

- **TailwindCSS 🌈**  
  Belajar styling dengan cara yang praktis dan cepat. Cukup gunakan utility class, maka desainmu langsung konsisten, responsif, dan siap dipakai tanpa ribet bikin CSS dari nol.

- **React ⚛️**  
  Bangun aplikasi web dengan cara baru yang lebih efisien. Dengan konsep komponen, kamu bisa membuat bagian-bagian UI yang bisa dipakai ulang, lebih terorganisir, dan mudah dikembangkan.

- **Next.js 🚀**  
  Jelajahi framework modern yang memadukan React dengan fitur-fitur canggih seperti routing, optimasi performa, dan SEO-friendly. Cocok banget untuk bikin website cepat, scalable, dan profesional.

- **React Native 📱**  
  Jangan cuma berhenti di web! Dengan React Native, kamu bisa membawa ilmu JavaScript ke dunia mobile, membangun aplikasi Android dan iOS dari satu codebase.

- **Electron 💻**  
  Bawa kemampuanmu lebih jauh lagi dengan membuat aplikasi desktop. Electron memungkinkanmu mengemas skill web menjadi software yang bisa jalan di Windows, Mac, maupun Linux.

those are some of the features of the template!

## Getting Started

To start using the template, you can use [degit](https://github.com/Rich-Harris/degit):

```bash
npx degit daltonmenezes/opendocs project_name
```

After cloning the repository, you can install the dependencies and run the project.

```bash
cd project_name
pnpm install
pnpm dev
```

After running the `pnpm dev` command, you can access the template at `http://localhost:3000`.
